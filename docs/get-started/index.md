# Get started

This section is shared front matter for both documentation tracks: it gets a new
installation working and takes it through one small, complete reconstruction, without
assuming which track you read next.

## What's here

- **[Installing Phaser](install.md)** — supported computational backends and optional
  dependencies, and how to confirm a working installation.
- **[Your first reconstruction](first-reconstruction.md)** — a small, complete simulated
  reconstruction, run end to end.
- **[Validating a plan](validate-a-plan.md)** — the `phaser validate` workflow and how to
  read validation errors.

## Suggested reading order

1. [Installing Phaser](install.md), to get a working environment.
2. [Validating a plan](validate-a-plan.md), since every reconstruction starts from a
   plan file and validation is the fastest way to check one before running it.
3. [Your first reconstruction](first-reconstruction.md), to run a small reconstruction
   end to end and see what a successful run produces.

After that, scientists preparing their own data should continue to the
[cookbook](../cookbook/index.md); contributors and extension authors should continue to
the [architecture guide](../architecture/index.md). Either path assumes the
[glossary](../concepts/glossary.md) as a shared reference for terminology.
